# Algorithm Problem Solving

BOJ 중심의 알고리즘 문제 풀이를 정리하는 저장소입니다.

C++로 자료구조, 그래프, DP, 세그먼트 트리, 기하, 구현 문제를 꾸준히 풀며 문제 해결 능력과 구현 속도를 높이는 것을 목표로 합니다.

## Solving Style

이 저장소는 풀이 설명을 길게 정리하기보다, 문제별 구현 코드를 빠르게 축적하는 방식으로 관리합니다.

주요 목표:

- 문제 조건을 정확히 모델링하기
- 시간/공간 복잡도에 맞는 자료구조 선택하기
- 구현 실수를 줄이기
- 실패한 풀이와 정답 풀이를 비교하며 패턴 익히기

일부 파일에는 `_ans`, `_another` suffix를 사용해 다른 풀이 또는 수정된 풀이를 함께 남겨두었습니다.
